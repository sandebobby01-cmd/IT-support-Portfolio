# IT Support Portfolio

I’m Bobby Sande, a Health Informatics graduate with experience helping colleagues at CHECK24 and Kredite24 troubleshoot laptops, monitors, docking stations, printers, and Wi-Fi. I also co-developed a handbook with tool instructions and examples to help onboard new team members.

## Work samples

- **Windows dock and monitor troubleshooting** — A simulated support ticket showing how to isolate a faulty USB-C cable, confirm the fix, and document the next step.
- **Microsoft 365 access on macOS** — A simulated support ticket showing how to distinguish a folder permission issue from a sign-in problem, request authorization, and keep the user informed.
- **Webex meeting-room readiness** — A sample knowledge-base article covering audio, camera, and screen-sharing checks, with a fallback plan if room audio fails before a meeting.

The support tickets use fictional incidents and outcomes.
